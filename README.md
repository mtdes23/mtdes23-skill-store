## 🚀 Cài Đặt & Chạy Cục Bộ

1. Clone mã nguồn:
```bash
git clone https://github.com/mtdes23/mtdes23-skill-store.git
cd mtdes23-skill-store
```

2. Chạy server thử nghiệm:
```bash
# Cách 1: Double click file start.bat (trên Windows)
# Cách 2: Chạy qua Python
python server.py
```
Website sẽ tự động mở tại `http://localhost:8080`.
